# GameDev1_WS25_Engine

This project was created during the MMArmelade-GameJam 2025 (GameJam submission state = state of Dec 9th 2025).

The main goal was to try and implement a data-oriented ECS mini-engine (using C++ & SFML) and then use that to create a small game for the GameJam - all withing the 48h given limit.
